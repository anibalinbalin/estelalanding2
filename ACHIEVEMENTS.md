## Project Overview

Estela is a Next.js application built with:
- **Next.js 15** with App Router
- **TypeScript** for type safety
- **Tailwind CSS v4** for styling
- **shadcn/ui** components (Radix UI based)
- **Motion** for animations

## Key Components

### Active Components
- `HeroSection` - Main hero section with content and infinite slider
- `InfiniteSlider` - Animated component showcasing company logos
- `ProgressiveBlur` - UI enhancement for smooth gradients
- `Button` - Reusable button component from shadcn/ui
- `Logo` - Brand logo component

### Removed Components
- `HeroHeader` - Top navigation bar (removed 2025-01-22)
